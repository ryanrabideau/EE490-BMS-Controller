# EE 490 - 24V Li-ion BMS Project

## System Overview
- **Topology:** 2P7S Li-ion Battery Pack (21.0V - 29.4V nominal)
- **Active Balancing:** Chained Switched Capacitor Topology
- **AFE / MCU:** ST L9963E + STM32F411RE

## Repository Structure
- `/firmware` - STM32 C/C++ source code and drivers
- `/pc_interface` - Python scripts for real-time telemetry logging
- `/docs` - System schematics and pinout references
