# Project Documentation

This directory contains the final documentation for the 24V Li-Ion Battery Management System senior design project.

## Final Deliverables

- [Final Project Report](EE490_BMS_Final_Report.pdf)
- [Final Project Poster](EE490_BMS_Final_Poster.pdf)

The final report documents the complete system design, including the battery pack, STM32 firmware, L9963E battery-monitoring hardware, sensing and protection functions, active cell balancing, LabVIEW PC interface, mechanical design, project management, and final project results.
